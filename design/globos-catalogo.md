# Globos números — catálogo por color

Referencia solicitada: https://casafessta.com.uy/globos/globo-numero (revisada el 3 de octubre de 2026).

El catálogo agrupa el producto de 32 pulgadas por color y ofrece los números 0–9 dentro de cada tarjeta. No se duplican productos en WooCommerce: cada formulario conserva número y color en la ficha existente. Cumpleaños y Globos comparten esta vista. Los accesos de 16 y 40 pulgadas siguen disponibles; esos productos todavía están pendientes.

Las imágenes doradas de referencia existentes se conservan. Los demás colores ahora tienen imágenes recreadas del 0 al 9, documentadas en design/globos-colores.md. No se copiaron fotografías de Casa Fessta.
