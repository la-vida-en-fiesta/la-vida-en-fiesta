# Halloween — primeras imágenes de catálogo

Cinco PNG con fondo blanco, recreados con la herramienta integrada image_gen a partir de fotos aportadas por el usuario. Precios en pesos uruguayos confirmados por el usuario. Se conserva tanto el número del archivo como el código de la etiqueta del proveedor; no se presupone cuál será el SKU de Hayden. Stock no informado.

Las imágenes son recreaciones para revisión, no fotos exactas del artículo desempaquetado. Se deben contrastar con el producto real antes de publicarlas. La del esqueleto colgante es una vista de detalle porque la referencia no muestra todo el artículo; el usuario pidió dejar solo los dos brazos hacia abajo.

`productos.json` asocia cada imagen con su precio y categoría. Todavía no se importaron en WooCommerce ni se modificó el catálogo público.

`prompts.md` conserva las instrucciones exactas usadas para generar las cinco imágenes y corregir el esqueleto.
